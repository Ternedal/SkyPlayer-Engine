# SkyPlayer Engine

Shared Unity/OpenXR VR playback engine extracted from [Ternedal/Skyplayer](https://github.com/Ternedal/Skyplayer).

> Bootstrap in progress. The existing Skyplayer application remains the production/reference client until its adapter has been migrated.

The engine is intended to be consumed by multiple clients, including Skyplayer and Kaliv-VR.
